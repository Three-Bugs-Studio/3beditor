# Security

3beditor runs entirely on your computer. It uploads nothing (see [PRIVACY.md](PRIVACY.md)).

## Reporting a problem

Please don't open a public issue for a security problem. Report it privately through [GitHub's security advisories](https://github.com/Three-Bugs-Studio/3beditor/security/advisories/new). You'll get a reply within 7 days.

Only the latest version is supported. Update with `/plugin marketplace update 3bstudio`.
